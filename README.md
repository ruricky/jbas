# JBAS — Journey Beyond Aerospace Society

A modern aerospace-themed website built for the JBAS student engineering initiative.  
Designed with cinematic UI, smooth animations, and a minimal aerospace-inspired aesthetic.

## 🚀 Live Site
https://jbas.tech

---

## 🧠 About

JBAS (Journey Beyond Aerospace Society) is a student-led engineering initiative focused on:
- High-altitude balloon systems (STRATOS)
- Amateur rocketry (ARMSTRONG)
- UAV logistics systems (AEROMED)

This website serves as the main landing page for showcasing programs, projects, and updates.

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (custom design system + animations)
- Vanilla JavaScript
- GitHub Pages hosting
- Custom domain (jbas.tech)

---

## ✨ Features

- Cinematic hero landing section
- Animated hamburger menu → slide-out navigation
- Glassmorphism UI side panel
- Interactive program cards with hover effects
- Parallax background motion
- Fully responsive design (mobile + desktop)
- Lightweight (no frameworks)

---

## 🔧 Running Locally

Simply open `index.html` in any browser.

For development, use Live Server in VS Code for best experience.
